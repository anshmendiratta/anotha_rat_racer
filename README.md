# Anotha Rat Racer

An [Odinlang](https://odin-lang.org/) implementation of all [three Ray Tracing in One Weekend books](https://raytracing.github.io/).

## How to Run

Requirements:
- https://devenv.sh/ (for reproducibility).

1. `devenv shell`
2. `devenv build`
3. `prun`
